SIAP DALAM SEMENIT.

Ringan di perangkat. Jelas caranya.

  1. 01
    Siapkan Python & dependency

    Python 3.10+ di Windows. Buka folder proyek lalu jalankan:

    python -m pip install -r requirements.txt
  2. 02
    Buka VALORANT sampai lobby

    Login seperti biasa. Aplikasi memakai sesi Riot Client lokal, bukan password akunmu.

  3. 03
    Jalankan GUI & pilih agentpython val.py

    Pilih agent dan region, lalu klik Mulai instalock. Masuk queue seperti biasa; aplikasi menunggu agent select.

Lock tidak dijamin berhasil. Agent harus sudah terbuka dan tersedia. Jika sudah diambil atau terjadi error, aplikasi berhenti agar tidak mengirim permintaan berulang.

  1. 01
    Jalankan tanpa akun VALORANTpython val.py --demo

    Tidak perlu dependency tambahan untuk mode demo.

  2. 02
    Coba tampilannya

    Cari dan filter agent, tandai favorit, lalu klik Mulai simulasi. Alur client → agent select → lock akan berjalan sebagai simulasi.

  3. 03
    Aman untuk eksplorasi

    Tombol berhenti bekerja kapan saja. Mode demo tidak menghubungi Riot dan tidak pernah mengunci agent sungguhan.
